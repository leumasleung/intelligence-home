車縫關鍵細節：

1. 後襠上口需比前襠抬高 3~4 cm (起襠)，防止坐下時後腰露縫或下滑。

2. 闊腿褲若想垂墜顯瘦，建議褲腳預留 3~4 cm 寬底邊貼邊縫份，增加下墜重量感。

標準縫份 (Seam Allowance) 建議

  • • 領口 / 腰頭 / 弧線部位：留 1.0 cm（弧度容易對齊且不易起包翻翹）。
  • • 側縫 / 襠骨 / 內側線：留 1.2 ~ 1.5 cm（保留試穿修改彈性）。
  • • 褲腳直線摺邊：留 3.0 ~ 4.0 cm（直筒下擺雙折更平整）。
  • • 全圓裙圓弧底擺：留 0.6 ~ 1.0 cm（密拷捲邊或三卷壓腳最適宜）。

常用車針與線號對照

  • • 9號 / 65號 車針：超薄絲綢、雪紡、真絲、薄薄紗。
  • • 11號 / 75號 車針：純棉襯衫布、人造絲、天絲洋裝。
  • • 14號 / 90號 車針（最萬用）：亞麻布、棉麻、西裝褲料。
  • • 16號 / 100號 車針：牛仔布、帆布、斜紋重磅厚褲。
  • • 車線：常規裁縫建議使用 50# 或 60# 聚酯滌綸線（不易起毛斷線）。

布料縮水與斜紗垂吊

  • • 裁布前必下水：純棉與亞麻縮水率約 5%~10%，務必先過水陰乾整燙後再裁切。
  • • 圓裙吊掛釋放斜紗：全圓裙或半圓裙的 45° 斜紗部位在重力下會拉長。車縫下擺前，最好先吊掛在衣架上 24 小時，修剪垂長後再包邊壓線。
